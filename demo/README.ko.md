# 직접 써 보기 위한 데모 맵

[English](README.md)

이 폴더의 파일은 모두 `tools/make_demo.py` 가 센서를 시뮬레이션해서 만든 것입니다. 그래서 실제 로봇이
남기는 것과 같은 종류의 결함이 들어 있고, 실제 치수도 알고 있습니다. 열어서 고친 뒤 아래 수치와
비교해 보세요.

```bash
./mapbarber.sh demo/office_octomap.bt demo/map_cloud.pcd demo/warehouse_map.yaml   # 탭 3개로 열림
```

## 폴더 구성

| 파일 | 열리는 편집기 | 시뮬레이션한 출처 | 일부러 넣은 문제 |
|---|---|---|---|
| `office_octomap.bt` | 복셀 편집기 | 깊이 카메라, 시점 14곳, 5 cm 복셀 | 플라잉 픽셀, 지나간 사람의 잔상, 검은 모니터의 구멍, 방을 가리는 천장 |
| `office_octomap_with_free.bt` | 복셀 편집기 | 같은 맵을 실시간 매핑 노드가 저장한 것 | 빈 공간 잎 60만 8천 개도 들어 있음 |
| `office_color.ot` | 복셀 편집기 | 같은 맵의 `ColorOcTree` | 복셀마다 색 |
| `office_octomap.bt.bak_20250101_090000` | 복셀 편집기 | 백업 사본 | 쓸 수 있는 확장자가 없음 |
| `office_voxels.npz` | 복셀 편집기 | NumPy 복셀 묶음 | — |
| `map_cloud.pcd` | 포인트 클라우드 편집기 | 깊이 카메라 점 12만 개 | 이상점, 플라잉 픽셀; `intensity`·`rgb` 필드 |
| `depth_frame.pcd` | 포인트 클라우드 편집기 | 정렬형 320 × 240 프레임 하나, 카메라 광학 좌표계 | 픽셀 39 % 무효(NaN), 경계 번짐 |
| `lidar_sweep.ply` | 포인트 클라우드 편집기 | 16채널 LiDAR 한 바퀴 | 먼지 반사; `intensity`·`ring`·`time` 필드 |

| `warehouse_map.yaml` + `.pgm` | 격자 편집기 | 2D LiDAR SLAM, 50 × 40 m, 5 cm 칸 | 잡티, 이중 벽 잔상, 사람이 지나간 흔적, 미지 구멍, 열린 출입구, 미지 테두리 |
| `lab_map.yaml` + `.png` | 격자 편집기 | `negate: 1` 과 회전된 원점(yaw 0.35 rad)의 map_server 맵 | 잡티 |
| `keepout_mask.yaml` + `.pgm` | 격자 편집기 | `mode: raw` 코스트맵 필터 마스크 | — |
| `drive/` | 포인트 클라우드 편집기(라벨링 모드) | pose 가 있는 거리 LiDAR 16프레임(KITTI 구조), 클래스 목록, 잡음 섞인 모델 예측 | 걷는 사람, 센서 쪽으로 오는 차, 연석 주변의 틀린 예측 |
| `broken_truncated.bt` | — | 60 % 지점에서 잘린 옥트리 | 거부되어야 함 |
| `not_a_map.yaml` | — | 맵이 아닌 파라미터 파일 | 거부되어야 함 |
| `not_points.txt` | — | 회의록 | 거부되어야 함 |

## 실제 치수 (자 기능 확인용)

| 맵 | 대상 | 실제 값 |
|---|---|---|
| office | 방 안쪽, x / y 방향 벽 사이 | 8.00 m / 6.00 m |
| office | 책상 윗면 높이 | 0.75 m |
| office | 남쪽 벽(y = 0)의 출입문 | 폭 1.00 m, x 1.0–2.0 m |
| office | 기둥 | 0.40 × 0.40 m |
| office | 사람 잔상 | x 5.2–5.5, y 4.0–4.3, 높이 1.75 m |
| warehouse | 랙 간격 (외곽선에서 외곽선) | 5.00 m (100 px) |
| warehouse | 랙 사이 통로 | 3.80 m (빈 칸 76개) |
| warehouse | 랙 | 1.20 m × 24.0 m |
| warehouse | 동쪽 벽 출입구 | 5.0 m (맵 y −5 … 0) |

복셀 측정은 표면에서 표면까지이고, 벽에 잡음이 붙어 있으면 한 복셀(5 cm) 정도 차이가 날 수 있습니다.
중심 간 거리를 보려면 *복셀 중심에 맞추기* 를 켜세요.

## 시나리오

### 1. 잡음 많은 복셀 맵 정리 — `office_octomap.bt`

1. **슬라이스** ▸ *공간 자르기*, 축 Z, 위치 2.9 m, *평면 아래쪽* 남기기. 천장이 사라지고, 숨겨져
   보호되는 복셀 수가 상태 표시줄에 나옵니다. 평면의 파란 화살표를 끌면 자르는 위치가 움직입니다.
2. **고립 덩어리** ▸ *작은 고립 덩어리 선택* (최대 20). 떠 있는 덩어리 약 1,550개(복셀 약 2,190개)가
   분홍색이 됩니다. `Delete` 를 누르세요.
3. 책상 동쪽(x 5.2–5.5, y 4.0–4.3)에 사람 잔상이 남아 있습니다. `V` 를 누르고 `Shift`+끌기로 감싼 뒤
   `Delete`. 잘못 선택한 복셀은 오른쪽 클릭으로 선택 해제됩니다.
4. 측정: `I` 를 누르고 서쪽 벽을 클릭한 뒤, `Shift` 를 누른 채 동쪽 벽을 클릭합니다. 자가 x 축으로
   고정되고 약 8.00 m 가 나옵니다. 같은 방법으로 z 방향 책상 높이(0.75 m)를 재 보세요.
5. **상자**: *상자 표시* 를 켜고, 색깔 화살표를 끌어 검은 모니터(x 2.6–3.0, y 3.6–3.65,
   z 0.75–1.1) 위로 옮기고 점을 끌어 크기를 맞춘 뒤 *상자 채우기*. 모니터의 구멍이 메워지고, 새 복셀은
   저장하기 전까지 흰색으로 보입니다.
6. *보기 복구*. 천장이 그대로 돌아옵니다. 숨겨진 쪽 복셀은 한 번도 편집되지 않았습니다.
7. `Ctrl+Z` 로 모든 편집을 한 단계씩 되돌리고 `Ctrl+Shift+Z` 로 다시 실행합니다. `Ctrl+Shift+S` 로
   `.bt` 로 저장한 뒤 다시 열면 상태 표시줄의 개수가 같습니다.

### 2. 다른 옥트리 변형들

`office_octomap_with_free.bt`, `office_color.ot`, `.bak_…` 사본, `office_voxels.npz` 를 여세요.
각각 자기 탭에서 시나리오 1과 같은 123,596개 복셀로 열립니다. `Ctrl+Tab` 으로 오갈 수 있습니다.

### 3. 포인트 클라우드 정리 — `map_cloud.pcd`

1. *색 기준* ▸ *저장된 색*, 그다음 *intensity*.
2. **잡음 필터** ▸ *이상점 선택* → `Delete`; *드문 점 선택* → `Delete`.
3. `E` 를 누르고 `[` / `]` 로 붓 반지름을 조절해 남은 잡티를 쓸어 지웁니다.
4. Z 축으로 잘라 책상 아래를 보고, `I` 로 바닥에서 책상 윗면까지(약 0.75 m) 재 보세요.
5. `.pcd` 로 저장하고 다시 열면 `intensity` 와 `rgb` 필드가 그대로 있습니다.

### 4. 깊이 프레임 하나 — `depth_frame.pcd`

정렬형(320 × 240) 프레임이고 카메라 광학 좌표계(z 가 앞쪽)입니다. NaN 픽셀은 자동으로 건너뛰어 약
46,900개 점이 보입니다. 앞 물체와 뒷배경 사이의 번짐은 전형적인 경계 잡음입니다. *드문 점 선택* 이나
`Shift`+끌기로 지우세요. 저장하면 정렬되지 않은 클라우드로 기록됩니다.

### 5. LiDAR 필드 — `lidar_sweep.ply`

*intensity* 와 *ring* 으로 색을 칠해 보세요. 먼지 반사는 짧고 약하고 흩어져 있어서 *드문 점 선택* 으로
대부분 지워집니다. `ring` 과 `time` 은 `.ply` 나 `.pcd` 로 저장해도 남습니다.

### 6. 텍스트와 NumPy 점

`colored_points.xyz` 는 저장된 색으로 보이고, `survey_points.csv` 는 머리글과 라벨 열을 무시하고 열리며,
`cloud_points.npy` 는 일반 점으로 열립니다.

### 7. 2D SLAM 맵 수리 — `warehouse_map.yaml`

1. *잡티 지우기* (최대 4칸).
2. 세 번째 랙 옆의 가는 세로선은 루프 클로저 오차로 생긴 이중 벽입니다. `L` 을 누르고 *빈 공간*(`F`),
   펜 3칸으로 놓은 뒤 `Shift` 를 누른 채 그 선을 따라 끌면 정확히 세로로 그려집니다.
3. 두 번째 통로의 구불구불한 점선은 지나간 사람입니다. `B` 로 *빈 공간* 을 칠해 지우세요.
4. 동쪽 벽의 열린 출입구 닫기: *점유*(`O`), `L`, 틈을 따라 `Shift`+끌기.
5. 남쪽 벽 근처의 회색 미지 구멍 채우기: *빈 공간*, `G`, 안쪽을 클릭.
6. `I` 와 `Shift` 로 랙 간격 재기: 한 랙의 왼쪽 외곽선을 클릭하고 다음 랙의 왼쪽 외곽선을 클릭하면
   5.00 m, 100 px.
7. *미지 테두리 잘라내기*: 맵이 작아지고 원점이 바뀌지만 아무것도 움직이지 않습니다. 같은 랙을 다시
   재 보세요.
8. `Ctrl+S` 를 누르면 `.pgm` 과 `.yaml` 이 함께 저장됩니다.

### 8. map_server 세부 사항 — `lab_map.yaml`, `keepout_mask.yaml`

* `lab_map` 은 `negate: 1` 과 회전된 원점을 씁니다. 빨강·초록 화살표가 회전된 맵 축을 가리키고, 자의
  Δx / Δy 는 맵 좌표계 기준입니다. 저장해도 `negate` 가 유지됩니다.
* `keepout_mask` 는 `raw` 마스크입니다. *점유* 로 `R` 을 써서 진입 금지 구역을 그리고(`Shift` 는
  정사각형, `Alt` 는 중심에서부터), 저장한 뒤 다시 열면 구역이 남아 있고 파일도 여전히 `raw` 입니다.

### 9. 새 탭에서의 변환

office 복셀 맵에서 **변환 ▸ 2D 점유 격자로…** 를 고르고 높이 구간 0.1–1.8 m 를 주면, 복셀 맵은 그대로
열린 채 평면도가 새 탭에 열립니다. `map_cloud.pcd` 를 복셀 맵으로 바꾸거나, warehouse 맵을 높이 2 m 의
벽으로 세워 보세요.

### 10. LiDAR 시퀀스 라벨링 — `drive/`

```bash
./mapbarber.sh demo/drive
```

1. 폴더가 자체 클래스(`labels.yaml`)와 함께 라벨링 모드로 열립니다. 화면 아래 타임라인의 오른쪽 손잡이를
   5번 프레임까지 끌면 여섯 프레임이 pose 로 합쳐집니다.
2. **지면 필터** ▸ *지면 선택* 후 *road* 를 현재 클래스로 두고 `Enter`. 연석은 라벨 붓 `B`(*sidewalk*)로
   고칩니다. `Ctrl`+끌기는 화면을 고정한 채 칠합니다.
3. `W` 를 누르고 주차된 차를 클릭하면 아래 도로 없이 차만 잡힙니다. *parked car* 를 고르고 `Enter`.
   *라벨된 포인트 보호*가 켜져 있으면, 거리 전체를 사각형으로 선택해도 아직 라벨이 없는 것만 선택됩니다.
4. *parked car* 를 현재 클래스로 두고 *자동 3D 박스: parked car*를 누릅니다. 차마다 별도 물체와
   박스가 생기고, 박스 목록에서 돌리거나 크기를 바꿀 수 있습니다.
5. *자동 3D 박스 라벨링 ▶ 시간순(앞으로)*은 첫 프레임의 박스와 물체 번호를 뒤 프레임으로 이어 붙이고
   (◀ 역순은 중간 프레임에서 라벨한 물체를 앞 프레임으로 따라갑니다), 단계마다의 점수를 박스 목록에
   보여 줍니다.
6. *라벨 불러오기…* ▸ `drive/predictions` 를 고르면 모델의 예측이 아직 라벨 없는 포인트에 흐린 제안으로
   들어옵니다. *주변과 다른 라벨 선택*은 연석 주변의 틀린 예측을 보여 줍니다.
7. `Ctrl+S` 는 `labels/*.label` 과 `boxes/*.json` 을 쓰고, *표준 형식으로 내보내기…* 는 SemanticKITTI
   시퀀스와 KITTI·OpenPCDet 박스를 씁니다. 모든 단계는 `Ctrl+Z` 로 되돌릴 수 있습니다.

### 11. 깨진 입력

깨진 파일 세 개를 여세요(한꺼번에 끌어다 놓아도 됩니다). 각각 짧은 이유와 함께 거부되고, 다른 탭에는
영향이 없습니다.

### 12. 명령행

```bash
./mapbarber.sh demo/office_octomap.bt --info
./mapbarber.sh demo/office_octomap.bt --remove-islands 20 -o /tmp/office_clean.bt
./mapbarber.sh demo/office_octomap.bt --z-band 0.1 1.8 -o /tmp/office_floor.yaml
./mapbarber.sh demo/warehouse_map.yaml --clear-speckles 4 -o /tmp/warehouse_clean.yaml
./mapbarber.sh demo/map_cloud.pcd --remove-outliers 16 2.0 -o /tmp/cloud_clean.pcd
./mapbarber.sh demo/broken_truncated.bt --info        # 종료 코드 1과 메시지
```

## 성능 확인용 세트 (저장소에는 없음)
